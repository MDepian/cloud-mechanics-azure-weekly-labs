## 🚀 How to Use These Labs

### 👀 Watch-Only Mode
Just follow along during the live session on **Microsoft Teams** every Wednesday at **8:00 PM Egypt Time**. Recordings are uploaded after each session.

### 💻 Hands-On Mode
1. Open the session folder before the session starts
2. Read the `README.md` for objectives and context
3. Follow the `lab-guide.md` step-by-step during the session
4. Use `resources.md` for deeper reading afterward

### 🔁 Self-Study Mode
All materials are self-contained — you can go through any session at your own pace, in any order that fits your learning journey.
